> Rascunho. Será preenchido na Semana 2 (Matheus), conforme as telas do Lucas entrarem na `main`.

## O que este sistema faz

Registra empréstimos e devoluções de componentes eletrônicos dos laboratórios do C3/FURG em menos de 5 segundos, via QR Code no celular.

## Como começar

1. Acesse o endereço do sistema (no laboratório ou via túnel HTTPS no celular).
2. Faça login com matrícula/e-mail e senha.
3. Use **Escanear** para apontar a câmera ao QR Code da caixa.
4. Toque em **Pegar** ou **Devolver**.
